# Shrijan & Garima

A small multi-page site: home, our story, gallery, and a final page.

## Pages
- `index.html` — landing page
- `story.html` — timeline
- `gallery.html` — photos and video
- `propose.html` — the last page

## Publish with GitHub Pages
1. Create a new repository on GitHub (e.g. `shrijan-garima`).
2. Push everything in this folder to the repo root (keep the `assets/` folder as is, and `index.html` at the top level).
3. In the repo, go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to `Deploy from a branch`, branch `main`, folder `/ (root)`.
5. Save. GitHub will give you a URL like `https://<username>.github.io/<repo-name>/` within a minute or two.

## Notes
- All links between pages are relative, so it works the same locally, on GitHub Pages, or on a custom domain.
- The video in `assets/video/us.mp4` is small on purpose so it loads fast on mobile.
